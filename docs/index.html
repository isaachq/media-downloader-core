Made for the big jobs

Most downloaders handle one video at a time. This one is built for a whole playlist, a whole profile, a whole search — and for leaving it running while you do something else.

Whole playlists and profiles

YouTube playlists, channels and Mixes; TikTok videos, short links and entire profiles — with “Load all” for the thousands of posts of a veteran account.

Pick before you download

A preview lists everything a link holds, with length and publication date. Filter, select all or just a few — only what you pick is downloaded.

Every file verified

Each download is checked before it is delivered — codecs, duration, every frame decoded — and its SHA-256 is recorded. A broken file is downloaded again, not handed to you.

Everything finished, in one place

The Finished tab keeps every file of every session: search it, play it, show it in its folder. It even tells you if a file was moved or deleted since.

A live report of the whole run

What is pending, downloading, being verified and finished — per batch, with time left, refreshed every 15 seconds. Copy it as text with one click.

Knows your disk and your time

Before it starts, a batch tells you how much space it needs. While it runs, the time left is measured from your computer's real speed — start a big batch and walk away.

Plays in your car and on your TV

MP4 in H.264/AAC, MP3 with the tags car stereos read, and file names with plain letters and numbers that every USB stick accepts. Or M4A, Opus, FLAC, WAV, WebM, MKV.

Sorted by when it was published

Each file carries the date it was published, so sorting a folder by date sorts your backup by publication — not by the minute it happened to download.

Keeps itself up to date

New versions arrive inside the app: one button downloads them, checks them against GitHub's SHA-256, installs and restarts. Its tools (yt-dlp, FFmpeg) set themselves up the same way.

Three steps

No command line, no settings to learn first. English or Spanish, light or dark.

Paste a link

A video, a playlist, a channel or a TikTok profile.

Pick what you want

Everything it holds is listed first. Choose MP4 or MP3, the quality and the folder.

Let it work

Several downloads at once, each one verified. Watch the report, or come back later.

Download

The newest version is always on GitHub Releases.

macOS

  • Apple Silicon (M1–M4).dmg
  • Intel.dmg

First launch: System Settings → Privacy & Security → “Open Anyway” (once). It isn't signed with a paid Apple certificate yet.

No “Open Anyway” button? Drag the app to Applications and run this once in Terminal:

xattr -dr com.apple.quarantine "/Applications/Media Download Core.app"

Windows

  • 64-bit (most PCs).exe
  • ARM64.exe
  1. Open the .exe. If a blue window says “Windows protected your PC”, click More info.
  2. Click Run anyway. The installer opens, finishes by itself and starts the app.

Why the warning? This is a free project made at home, and it isn't signed with a paid Microsoft certificate yet. The warning is about that missing signature, not about the file — its code is public on GitHub, and Windows stops asking as more people install it.
