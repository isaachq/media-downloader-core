1. Resumen y compromiso con la privacidad

Media Download Core para Android está construida con una arquitectura estrictamente privacy-first:

  • Sin datos personales: No se recopila nombre, correo, contactos, ubicación, ID de publicidad ni nada de lo que descargas.
  • Estadísticas de uso anónimas, a tu elección: Desde la versión 0.2.0-beta.45 la app puede enviar estadísticas de uso anónimas (Firebase Analytics) para que el mantenedor sepa qué funciones se usan y qué falla. Está activada por defecto y puedes apagarla en cualquier momento en Ajustes > Privacidad.
  • Cero anuncios, cero venta de datos: No hay anuncios ni rastreadores publicitarios. Nunca vendemos datos de usuarios ni los usamos para publicidad.

3. Estadísticas de uso anónimas (Firebase Analytics)

Por qué: la app la desarrolla una sola persona y su propio teléfono no es el mundo real. Saber qué funciones se usan, qué sitios y formatos fallan y con qué error, es cómo mejora la app. No hay monetización detrás.

Qué se envía (solo mientras la opción está activada):

  • Eventos: una descarga empezó, terminó, falló, se canceló o se omitió; se programó un lote o lista mixta; se leyó un enlace; empezó o terminó una grabación en vivo; inicio o cierre de sesión; se abrió una pantalla; se usó una función como compartir o reintentar.
  • Con cada evento, solo códigos cortos y números: el sitio (por ejemplo tiktok), el formato (por ejemplo mp4_1080), el código y paso de error del motor, intentos, tamaño del archivo en MB y duración.
  • Tipo de dispositivo (teléfono o tablet) y ajustes en uso: idioma de la app, tema, formato por defecto, segundo plano, solo Wi-Fi, galería, modo de reintento, verificación de integridad.
  • Lo que Firebase agrega por sí mismo: un ID de instancia de la app (aleatorio, se reinicia al borrar datos o reinstalar), versión de la app, versión de Android, modelo del dispositivo, país, y cuánto tiempo está en uso la app y cada pantalla.

Qué nunca se envía: enlaces (URLs), títulos, nombres de usuario, canal o cuenta, nombres de archivo o carpetas, mensajes de error, cookies o sesiones, el ID de publicidad o el Android ID.

Tu control: Ajustes > Privacidad > Compartir estadísticas de uso anónimas. Apagarla detiene la recopilación de inmediato y se mantiene apagada entre reinicios. Borrar los datos de la app o reinstalar reinicia el ID aleatorio de instancia.

Procesador y retención: Google LLC (Firebase Analytics) procesa los datos para el mantenedor bajo los términos de Firebase. Las señales de personalización de anuncios están desactivadas. Los datos se conservan durante el periodo de retención configurado en Firebase y luego se eliminan. Los datos no están vinculados a tu identidad.

4. Permisos del dispositivo y casos de uso

  • POST_NOTIFICATIONS (Android 13+): Se usa únicamente para mostrar la barra de progreso de descarga y el estado de finalización mientras las descargas corren en segundo plano.
  • Servicio en primer plano (dataSync - Android 14+): Se usa exclusivamente mientras hay descargas activas iniciadas por el usuario, para evitar que Android mate prematuramente el worker de Node.js en segundo plano.
  • Storage Access Framework (SAF): Cuando eliges una carpeta de destino personalizada se usa el selector nativo de Android. La app no solicita ni usa el permiso amplio MANAGE_EXTERNAL_STORAGE.

5. Propiedad intelectual y avisos de no afiliación

Media Download Core es un proyecto de código abierto independiente y no está respaldado, afiliado, asociado ni autorizado por TikTok, ByteDance, Instagram, Facebook ni Meta Platforms.

Media Download Core está pensada para archivado personal, visualización sin conexión y copias de seguridad educativas de media que posees o para la cual tienes autorización legal explícita del creador. Los usuarios deben cumplir las leyes de derechos de autor aplicables y los Términos de Servicio de los proveedores de contenido.
