1. Overview & Commitment to Privacy

Media Download Core for Android is built with a strict privacy-first architecture:

  • No Personal Data: No name, email, contacts, location, advertising ID, or anything you download is collected.
  • Anonymous Usage Statistics, Your Choice: Since version 0.2.0-beta.45 the app can send anonymous usage statistics (Firebase Analytics) so the maintainer learns which features are used and what fails. It is on by default and you can turn it off at any time in Settings > Privacy; off stops it immediately.
  • Zero Ads, Zero Selling: There are no ads and no advertising trackers. We never sell user data or use it for advertising.

3. Anonymous Usage Statistics (Firebase Analytics)

Why: the app is developed by one person, and their own phone is not the real world. Knowing which features are used, which sites and formats fail and with which error, is how the app improves. There is no monetization behind it.

What is sent (only while the setting is on):

  • Events: a download started, finished, failed, was cancelled or skipped; a batch or mix list was scheduled; a link was read; a live recording started or ended; a sign-in or sign-out; a screen was opened; a feature such as share or retry was used.
  • With each event, only short codes and numbers: the site (for example tiktok), the format (for example mp4_1080), the engine's error code and step, attempts, file size in MB and duration.
  • Device type (phone or tablet) and settings in use: app language, theme, default format, background, Wi-Fi only, gallery, retry mode, integrity check.
  • What Firebase adds by itself: an app instance ID (random, reset when you clear the app's data or reinstall), app version, Android version, device model, country, and how long the app and each screen are in use.

What is never sent: links (URLs), titles, user, channel or account names, file names or folders, error messages, cookies or sessions, the advertising ID or the Android ID.

Your control: Settings > Privacy > Share anonymous usage statistics. Turning it off stops collection immediately and stays off across restarts. Clearing the app's data or reinstalling resets the random instance ID.

Processor and retention: Google LLC (Firebase Analytics) processes the data for the maintainer under the Firebase terms. Ad personalization signals are disabled. Data is kept for the retention period configured in Firebase and then deleted. The data is not linked to your identity.

4. Device Permissions & Use Cases

  • POST_NOTIFICATIONS (Android 13+): Used solely to display the download progress bar and completion status while downloads run in the background.
  • Foreground Service (dataSync - Android 14+): Used exclusively while active, user-initiated downloads are in progress to prevent Android from prematurely killing the background Node.js download worker.
  • Storage Access Framework (SAF): When you choose a custom destination folder, Android's native directory picker is used. The app does not request or use broad MANAGE_EXTERNAL_STORAGE permissions.
