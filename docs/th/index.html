วางลิงก์ เลือกสิ่งที่ต้องการ แล้วปล่อยให้แอปดาวน์โหลดวิดีโอหรือเพลงหลายร้อยรายการพร้อมตรวจสอบทุกไฟล์ — จากนั้นพบทั้งหมดได้ในที่เดียว พร้อมเล่น

มีอะไรใหม่ในเบต้า 20

หกเบต้านับตั้งแต่หน้านี้อัปเดตครั้งล่าสุด: ลิงก์จากเว็บไซต์ใดก็ได้ในชุดเดียว อ่าน VK และ X ได้โดยตรง ช่องเดียวสำหรับทุกเว็บไซต์ แอปสิบสี่ภาษา และหน้าตาใหม่

รายการผสม: เว็บไซต์ใดก็ได้ ชุดเดียว

เพิ่มลิงก์ทีละรายการหรือวางทั้งรายการ — YouTube, TikTok, Instagram, Facebook, VK, X, ไฟล์ ทั้งหมดถูกตรวจสอบพร้อมกัน และก่อนจะดาวน์โหลดอะไร คุณจะเห็นว่าจะดาวน์โหลดอะไร อะไรถูกข้าม และเพราะอะไร คลิกเดียวดาวน์โหลดทั้งหมดเป็นชุดเดียว

รูปแบบ สำหรับทั้งหมดหรือแต่ละลิงก์

เลือก MP4 คุณภาพดีที่สุดหรือเสียงสำหรับทั้งรายการ — หรือกำหนดรูปแบบเฉพาะให้ลิงก์เดียว เช่น เพลง MP3 ท่ามกลางวิดีโอ ยังคงเป็นชุดเดียว โฟลเดอร์เดียว

VK และ X โดยตรง

วิดีโอ คลิป และเพลย์ลิสต์ของ VK สูงสุด 1080p และโพสต์ X ที่มีวิดีโอหนึ่งหรือหลายรายการ GIF และวิดีโอที่ถูกอ้างอิง — โดยไม่ต้องลงชื่อเข้าใช้

ช่องเดียวสำหรับทุกเว็บไซต์

วางลิงก์ใดก็ได้ แล้วแอปจะรู้จักเว็บไซต์เอง ไม่ต้องเลือกเว็บไซต์ทุกเซสชันหรือรีสตาร์ตเพื่อเปลี่ยนอีกต่อไป

สิบสี่ภาษา

สเปน อังกฤษ โปรตุเกส อินโดนีเซีย ฮินดี เวียดนาม ไทย ตุรกี อาหรับ (ขวาไปซ้าย) ฝรั่งเศส เยอรมัน รัสเซีย จีน และอิตาลี

หน้าตาใหม่

ตราแมวป่าที่มีลูกศรดาวน์โหลดบนหน้าผาก บนแอป ตัวติดตั้ง และหน้านี้ เบื้องบนเป็นเช่นไร เบื้องล่างก็เป็นเช่นนั้น

สร้างมาเพื่องานใหญ่

ตัวดาวน์โหลดส่วนใหญ่จัดการได้ทีละวิดีโอ ตัวนี้สร้างมาสำหรับทั้งเพลย์ลิสต์ ทั้งโปรไฟล์ ทั้งผลการค้นหา — และทำงานต่อไปขณะที่คุณทำอย่างอื่น

เพลย์ลิสต์และโปรไฟล์ทั้งหมด

เพลย์ลิสต์ ช่อง และมิกซ์ของ YouTube; วิดีโอ สไลด์โชว์ และภาพหมุนของ TikTok, Instagram และ Facebook (เป็นวิดีโอ หรือเป็นภาพพร้อมเสียง) และโปรไฟล์ทั้งหมด; วิดีโอและเพลย์ลิสต์ VK; โพสต์ X — พร้อม “โหลดทั้งหมด” สำหรับโพสต์นับพันของบัญชีเก่า

เลือกก่อนดาวน์โหลด

หน้าตัวอย่างแสดงทุกอย่างในลิงก์ พร้อมความยาวและวันที่เผยแพร่ กรอง เลือกทั้งหมดหรือเพียงบางรายการ — ดาวน์โหลดเฉพาะที่คุณเลือก หรือรวมลิงก์จากเว็บไซต์ใดก็ได้ในรายการผสม: ชุดเดียว พร้อมรูปแบบที่คุณเลือกให้แต่ละลิงก์

ทุกไฟล์ผ่านการตรวจสอบ

ทุกการดาวน์โหลดถูกตรวจสอบ — โคเดก ความยาว ถอดรหัสทุกเฟรม — และบันทึก SHA-256 ไว้ ไฟล์ที่เสียจะถูกดาวน์โหลดใหม่ ไฟล์ที่เสียตั้งแต่ต้นทางจะถูกทำเครื่องหมายและไม่ดาวน์โหลดซ้ำ

ทุกอย่างที่เสร็จแล้ว ในที่เดียว

แท็บเสร็จแล้วเก็บทุกไฟล์จากทุกเซสชัน ทีละชุด: ค้นหา เล่น แสดงในโฟลเดอร์ ตรวจสอบใหม่ ส่งออกรายการ หากมีอะไรล้มเหลว คลิกเดียวลองใหม่ — และคุณเห็นสาเหตุ

รายงานสดของทั้งการทำงาน

สิ่งที่รอ กำลังดาวน์โหลด กำลังตรวจสอบ และเสร็จแล้ว — แยกตามชุด พร้อมเวลาที่เหลือ รีเฟรชทุก 15 วินาที คัดลอกเป็นข้อความได้ในคลิกเดียว

รู้จักดิสก์และเวลาของคุณ

ก่อนเริ่ม ชุดจะบอกว่าต้องใช้พื้นที่เท่าไร ขณะทำงาน เวลาที่เหลือวัดจากความเร็วจริงของคอมพิวเตอร์คุณ — เริ่มชุดใหญ่แล้วไปทำอย่างอื่นได้เลย

เล่นได้ในรถและบนทีวี

MP4 แบบ H.264/AAC, MP3 พร้อมแท็กที่เครื่องเสียงรถยนต์อ่านได้ และชื่อไฟล์ที่ใช้ตัวอักษรและตัวเลขธรรมดาซึ่งแฟลชไดรฟ์ทุกตัวรองรับ หรือ M4A, Opus, FLAC, WAV, WebM, MKV

เรียงตามวันที่เผยแพร่

ทุกไฟล์มีวันที่เผยแพร่ติดอยู่ การเรียงโฟลเดอร์ตามวันที่จึงเรียงข้อมูลสำรองตามการเผยแพร่ — ไม่ใช่ตามนาทีที่ดาวน์โหลด

อัปเดตตัวเอง

เวอร์ชันใหม่มาถึงในแอป: ปุ่มเดียวดาวน์โหลด ตรวจสอบด้วย SHA-256 ของ GitHub ติดตั้ง และรีสตาร์ต เครื่องมือของแอป (yt-dlp, FFmpeg) ก็ติดตั้งแบบเดียวกัน

Sync Up: บัญชีที่อัปเดตอยู่เสมอ

เชื่อมบัญชี TikTok กับโฟลเดอร์ของมัน — แม้โฟลเดอร์ที่มีวิดีโออยู่แล้ว — แล้วการซิงก์แต่ละครั้งจะนำมาเฉพาะสิ่งที่ยังขาด ในรูปแบบของโฟลเดอร์ ทุกวันตามเวลาที่ตั้งไว้ ทุกไม่กี่ชั่วโมง หรือเมื่อใดก็ได้ที่คุณต้องการ

แจ้งเมื่อเสร็จ

ปล่อยให้ทำงานเบื้องหลัง: การแจ้งเตือนของระบบจะมาเมื่อชุดเสร็จ และไอคอนใน Dock หรือแถบงานจะแสดงความคืบหน้า

มีทั้งบรรทัดคำสั่งและไลบรารี

เอนจินเดียวกันทำงานจากเทอร์มินัล (mdc) และจากโค้ดของคุณเอง — ตั้งเวลาซิงก์บัญชีด้วย cron, launchd หรือ Task Scheduler โดยไม่ต้องเปิดแอป

สามขั้นตอน

ไม่ต้องใช้บรรทัดคำสั่ง ไม่ต้องเรียนรู้การตั้งค่าก่อน — ครั้งแรกจะมีคู่มือสั้น ๆ พาชม สิบสี่ภาษา โหมดสว่างหรือมืด

วางลิงก์

วิดีโอ เพลย์ลิสต์ ช่อง โปรไฟล์ TikTok, Instagram หรือ Facebook โพสต์ VK หรือ X — หรือรายการลิงก์ทั้งชุดจากเว็บไซต์ใดก็ได้

เลือกสิ่งที่ต้องการ

ทุกอย่างในลิงก์จะแสดงรายการก่อน เลือก MP4 หรือ MP3 คุณภาพ และโฟลเดอร์

ปล่อยให้ทำงาน

ดาวน์โหลดหลายรายการพร้อมกัน ทุกรายการผ่านการตรวจสอบ ติดตามรายงาน หรือกลับมาทีหลัง

ดูตัวอย่าง

เนื้อหาส่วนตัว: ลงชื่อเข้าใช้ในเบราว์เซอร์

วิดีโอส่วนตัวหรือสำหรับสมาชิกเท่านั้น วิดีโอจำกัดอายุ โปรไฟล์และสตอรี่ Instagram วิดีโอของเพจ Facebook — และ YouTube เมื่อขอให้ยืนยันว่าคุณไม่ใช่บอท — ต้องใช้บัญชีของคุณเอง แอปไม่เคยขอรหัสผ่าน: ใช้เซสชันของเบราว์เซอร์ที่คุณลงชื่อเข้าใช้อยู่แล้ว

ลงชื่อเข้าใช้ในเบราว์เซอร์

Chrome, Edge, Firefox, Safari หรือ Brave — เข้า Google / YouTube, Instagram หรือ Facebook ตามปกติ

เลือกในแอป

การตั้งค่า → คุกกี้จากเบราว์เซอร์ → เบราว์เซอร์เดียวกัน “วิธีลงชื่อเข้าใช้” แสดงขั้นตอนเหล่านี้

อนุญาตครั้งเดียว

ระบบจะขออนุญาตในครั้งแรก (ดูของคุณด้านล่าง)

วางลิงก์อีกครั้ง

จะดาวน์โหลดด้วยเซสชันของคุณ ออกจากระบบแล้ว? ลงชื่อเข้าใช้อีกครั้งในเบราว์เซอร์

macOS

หน้าต่างพวงกุญแจจะขอให้อนุญาตให้แอปอ่าน “Chrome Safe Storage” (หรือของเบราว์เซอร์คุณ): พิมพ์รหัสผ่าน Mac แล้วคลิก อนุญาตเสมอ Safari: การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → การเข้าถึงดิสก์เต็มรูปแบบ → เปิด Media Download Core

Windows

ปิดเบราว์เซอร์ก่อนดาวน์โหลด — Chrome และ Edge ล็อกคุกกี้ขณะเปิดอยู่ หาก Chrome ยังอ่านไม่ได้ (บน Windows จะปกป้องคุกกี้) ให้ลงชื่อเข้าใช้ด้วย Firefox แล้วเลือก Firefox

Linux

บน Fedora, Ubuntu และอื่น ๆ พวงกุญแจของคุณ (GNOME Keyring / KWallet) อาจขออนุญาตเข้าถึงข้อมูลที่เบราว์เซอร์บันทึกไว้: ให้อนุญาต Firefox ไม่ถามอะไร

คุกกี้ของคุณอยู่บนคอมพิวเตอร์ของคุณ: ถูกอ่านครั้งเดียวไปยังสำเนาส่วนตัวที่ใช้เพื่อดาวน์โหลดเท่านั้น และไม่เคยถูกส่งไปที่อื่น
