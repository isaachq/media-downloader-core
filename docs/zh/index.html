Beta 20 新功能

自本页上次更新以来已有六个测试版：任意网站的链接合并为一个批次、原生读取 VK 和 X、所有网站共用一个输入框、应用支持十四种语言，以及全新的外观。

混合列表：任意网站，一个批次

逐个添加链接或粘贴整个列表——YouTube、TikTok、Instagram、Facebook、VK、X、一个文件。它们会一起检查，在下载任何内容之前，你就能看到将下载什么、跳过了什么以及原因。点一下，全部作为一个批次下载。

格式：统一设置或逐个链接设置

为整个列表选择最佳画质的 MP4 或音频——也可以给单个链接指定自己的格式，比如在视频中夹一首 MP3 歌曲。依然是一个批次、一个文件夹。

原生支持 VK 和 X

VK 视频、短片和播放列表，最高 1080p；X 帖子中的单个或多个视频、GIF 和引用视频——无需登录。

所有网站共用一个输入框

粘贴任意链接，应用会自动识别网站。不再需要每次会话选择网站，也不必为切换网站而重启。

十四种语言

西班牙语、英语、葡萄牙语、印度尼西亚语、印地语、越南语、泰语、土耳其语、阿拉伯语（从右到左）、法语、德语、俄语、中文和意大利语。

全新外观

额头带有下载箭头的野猫徽标，出现在应用、安装程序和本页上。如其在上，如其在下。

为大任务而生

大多数下载器一次只能处理一个视频。它专为整个播放列表、整个主页、整个搜索结果而设计——并且在你做别的事时持续运行。

整个播放列表和主页

YouTube 的播放列表、频道和合辑；TikTok、Instagram、Facebook、Threads、Bluesky、Snapchat 和 SoundCloud 的整个主页，包括轮播（作为视频，或作为带声音的图片）；Twitch 的视频和直播频道；X 和 VK —— 对老账号的成千上万条帖子，还有“全部加载”。

先选择，再下载

预览会列出链接中的所有内容，包括时长和发布日期。筛选、全选或只选几个——只下载你选中的内容。也可以把任意网站的链接放进混合列表：一个批次，每个链接用你选择的格式。

每个文件都经过校验

每次下载都会检查——编解码器、时长、逐帧解码——并记录其 SHA-256。损坏的文件会重新下载；源头就已损坏的文件会被标记，绝不重复下载。

所有完成的内容都在一处

“已完成”标签保留每次会话的每个文件，按批次排列：搜索、播放、在文件夹中显示、重新检查、导出列表。如果有失败，点一下即可重试——并能看到失败原因。

整个任务的实时报告

等待中、下载中、校验中和已完成的内容——按批次显示剩余时间，每 15 秒刷新。一键复制为文本。

了解你的磁盘和时间

开始前，批次会告诉你需要多少空间。运行时，剩余时间根据你电脑的实际速度计算——启动一个大批次，然后去忙别的。

车上和电视上都能播放

H.264/AAC 的 MP4，带有车载音响可读取标签的 MP3，以及任何 U 盘都能接受的简单字母和数字文件名。也支持 M4A、Opus、FLAC、WAV、WebM、MKV。

按发布日期排序

每个文件都带有其发布日期，因此按日期排序文件夹就是按发布时间排序你的备份——而不是按下载的那一分钟。

自动保持更新

新版本直接在应用内推送：一个按钮即可下载、用 GitHub 的 SHA-256 校验、安装并重启。其工具（yt-dlp、FFmpeg）也以同样方式安装。

Sync Up：账号保持最新

将 TikTok 账号与其文件夹关联——即使文件夹里已有它的视频——每次同步只补充缺少的内容，并使用该文件夹的格式。每天固定时间、每隔几小时，或随你所愿。

完成时通知你

让它在后台工作：批次完成时会弹出系统通知，程序坞或任务栏图标会显示进度。

还有命令行和库

同一引擎可在终端（mdc）和你自己的代码中运行——用 cron、launchd 或任务计划程序安排账号同步，无需打开应用。

三个步骤

无需命令行，也不用先学习设置——第一次使用时，简短的引导会带你熟悉。支持十四种语言，浅色或深色。

粘贴链接

一个视频、一个播放列表、一个频道、任一支持网站的主页、一个正在直播的 Twitch 频道 —— 或者任意网站的一整串链接。

选择你想要的

先列出其中的所有内容。选择 MP4 或 MP3、画质和文件夹。

让它工作

同时进行多个下载，每个都经过校验。查看报告，或稍后再回来。

看看效果

私密内容：在浏览器中登录

私密或仅限会员的视频、有年龄限制的视频、Instagram 主页和快拍、Facebook 主页的视频——以及 YouTube 要求确认你不是机器人时——都需要你自己的账号。应用从不索要密码：它使用你已登录的浏览器会话。

在浏览器中登录

Chrome、Edge、Firefox、Safari 或 Brave——照常登录 Google / YouTube、Instagram 或 Facebook。

在应用中选择它

设置 → 浏览器 Cookie → 同一个浏览器。“如何登录”会显示这些步骤。

允许一次

系统会在第一次时请求许可（下方是你的系统）。

再次粘贴链接

它会使用你的会话下载。已退出？在浏览器中重新登录。

macOS

钥匙串窗口会请求允许应用读取“Chrome Safe Storage”（或你浏览器的对应项）：输入 Mac 密码并点击始终允许。Safari：系统设置 → 隐私与安全性 → 完全磁盘访问权限 → 打开 Media Download Core。

Windows

下载前请关闭浏览器——Chrome 和 Edge 打开时会锁定其 Cookie。如果 Chrome 仍无法读取（在 Windows 上它会保护 Cookie），请用 Firefox 登录并选择 Firefox。

Linux

在 Fedora、Ubuntu 等系统上，钥匙环（GNOME Keyring / KWallet）可能会请求允许访问浏览器保存的数据：请允许。Firefox 不会询问。

你的 Cookie 留在你的电脑上：它们只被读取一次到仅用于下载的私有副本中，绝不会发送到其他地方。

下载

最新版本始终在 GitHub Releases 上。

macOS

  • Apple 芯片（M1–M4）.dmg
  • Intel.dmg

首次启动：系统设置 → 隐私与安全性 → “仍要打开”（一次）。它尚未使用付费的 Apple 证书签名。

没有“仍要打开”按钮？把应用拖到“应用程序”，然后在终端运行一次：

xattr -dr com.apple.quarantine "/Applications/Media Download Core.app"

Windows

  • 64 位（大多数电脑）.exe
  • ARM64.exe
  1. 打开 .exe。如果蓝色窗口显示“Windows 已保护你的电脑”，点击更多信息。
  2. 点击仍要运行。安装程序会打开，自动完成并启动应用。

为什么会有警告？这是一个在家开发的免费项目，尚未使用付费的 Microsoft 证书签名。警告针对的是缺少签名，而非文件本身——其代码在 GitHub 上公开，随着安装的人越来越多，Windows 将不再询问。
